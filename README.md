# FFc ⚽ Fútbol 3D

Juego de fútbol 3D en el navegador (Three.js). Tú (azul) contra la CPU (rojo).
Mete más goles en 2 minutos.

## Jugar
Abre `index.html` en un navegador. No necesita internet (Three.js va incluido en `libs/`).

## Controles
- **Mover:** joystick (táctil) o WASD / flechas
- **PATEAR:** botón o `Espacio` (cerca del balón)
- **BARRER:** botón o `Shift` (barrida con impulso)
- **CORRER:** botón (mantener) o `Shift` para sprint
